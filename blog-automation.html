이 영역은 실제 Windows 런처 화면을 그대로 복제한 것이 아니라, 고객이 공지·프로그램·업데이트·피드백 흐름을 이해하도록 만든 홈페이지용 예시입니다. 실제 프로그램 화면은 정식 배포 버전에 맞춰 교체될 수 있습니다.

왜 이 제품이 필요한가

콘텐츠 운영의 현실적인 문제들

1인 운영자, 소규모 팀, 에이전시 모두 같은 고민을 합니다. 좋은 주제는 있는데 글로 옮길 시간이 없고, 겨우 썼는데 퀄리티가 고르지 않고, 발행 직전에 검수를 놓칩니다.

⏳

초안 작성에 반나절이 사라진다

주제 조사, 구성, 초안, 퇴고까지 글 한 편에 4–6시간 이상. 루틴화가 어렵고, 포기하게 됩니다.

📉

발행 빈도가 들쑥날쑥하다

주 3편 목표로 시작했다가 월 2편으로 줄어드는 패턴. 검색 노출과 독자 신뢰 모두 하락합니다.

🔄

매번 처음부터 다시 반복한다

지난 달 잘 된 글의 패턴을 기억해 재적용하기 어렵습니다. 노하우가 사람이 아니라 시스템에 쌓여야 합니다.

🚨

검수 없이 발행했다가 수정이 쌓인다

사실 오류, 맞춤법, 브랜드 톤 불일치. 사후 수정 비용이 작성 비용보다 커지는 경우도 있습니다.

아르센의 접근

어떻게 작동하나요?

복잡한 설정 없이, 주제만 입력하면 AI 파이프라인이 단계별로 작업합니다. 각 단계에서 사용자가 검토하고, 승인된 내용만 다음 단계로 넘어갑니다.

1

주제 입력

키워드 또는 한 줄 설명을 입력합니다. 타겟 독자, 톤, 길이를 선택할 수 있습니다.

2

AI 초안 생성

리서처 → 라이터 → 팩트체커 → 에디터 순서로 단계별 초안이 자동 생성됩니다.

3

검토 및 승인

생성된 초안을 직접 확인하고 수정합니다. 승인 전까지 외부에 발행되지 않습니다.

4

발행 대기 → 확인 후 발행

승인된 글은 발행 대기 상태로 이동합니다. 최종 확인 후 원하는 시점에 발행하세요.

처음 시작하는 분을 위한 안내

어디를 눌러야 할지 모르는 분도
순서대로 따라오면 됩니다

이 제품은 AI 도구를 잘 아는 사람만 쓰는 화면이 아니라, 블로그 운영을 처음 자동화하는 사람도 “지금 무엇을 해야 하는지” 알 수 있도록 단계와 상태를 나눠 보여주는 것을 목표로 합니다.

처음 10분에 확인할 것

설치나 결제보다 먼저, 내 키워드가 어떤 흐름으로 글이 되는지 보는 것이 중요합니다. 체험 단계에서는 외부 발행을 연결하지 않고 초안 생성과 품질 확인부터 안내합니다.

  • 키워드 하나로 초안이 만들어지는지 확인
  • 검색 근거와 본문이 따로 정리되는지 확인
  • AI가 쓴 느낌이 강하면 재작성 요청 가능
  • 승인 전에는 네이버 블로그나 SNS에 게시되지 않음
  • 런처는 공지와 업데이트 확인을 돕는 선택 도구
1

키워드 또는 주제를 입력합니다

예: 산본 쭈꾸미, 신생아 가습기, 보조배터리처럼 짧게 넣어도 됩니다. 키워드가 너무 넓으면 AI가 먼저 의도 후보를 제안하고, 사용자가 방향을 선택합니다.

2

검색과 초안 작성이 분리되어 진행됩니다

검색 결과를 그대로 복사하지 않고, 후보를 걸러낸 뒤 글에 필요한 정보만 사용합니다. 맛집처럼 출처보다 자연스러운 소개가 중요한 글은 본문과 참고 정보를 분리합니다.

3

검증 점수와 개선 이유를 확인합니다

완성도, 검색 의도 적합성, 자연스러움, 사실 위험을 나눠 봅니다. 기준 점수에 못 미치면 같은 키워드로 다시 작성하거나 부족한 부분만 보강합니다.

4

승인된 글만 발행 준비로 이동합니다

초안, 평가, 참고 정보, 발행 계획을 따로 보관합니다. 네이버 블로그나 워드프레스 발행은 최종 승인 후 별도 단계에서 진행됩니다.

런처를 열었을 때 보이는 정보

공지 새 기능, 점검, 긴급 안내를 시작 화면에서 먼저 보여줍니다. 중요한 공지는 오늘 다시 보지 않기 전까지 유지됩니다.
업데이트 현재 버전, 최신 버전, 최소 지원 버전을 비교합니다. 오래된 버전이면 다운로드 안내와 오류 메시지를 보여줍니다.
프로그램 목록 손님이 쓰는 4개 프로그램만 보입니다. 운영자가 쓰는 점검 화면은 뒤에 따로 숨겨 평소에는 보이지 않습니다.
피드백 문제 상황을 보낼 수 있습니다. 로그 첨부는 동의 후 진행하며, 민감 정보는 저장 전에 마스킹합니다.

목적 내 키워드로 결과물이 나오는지 확인 반복 생성, 검증, 저장, 발행 준비까지 운영

처음 실행 가이드

처음 설치하는 사람도
이 순서대로만 확인하면 됩니다

Windows 런처는 앞으로 “실행 후 공지 확인 → 버전 확인 → 프로그램 선택 → 피드백 전송” 순서를 기준으로 정리합니다. 정식 배포 전에는 공식 경로와 보안 검증 안내를 먼저 보여줍니다.

1
공식 경로 확인비공식 파일을 받지 않도록 공식 안내 페이지에서 시작합니다.
2
공지 읽기긴급 안내, 점검, 업데이트 권장 사항을 먼저 확인합니다.
3
버전 검증현재 버전과 최신 버전, SHA-256 파일 검증 상태를 봅니다.
4
보안 경고 확인인터넷에서 받은 설치 파일은 Windows 경고가 보일 수 있어 공식 파일 여부와 서명 상태를 다시 확인합니다.
5

정식 다운로드는
검증이 끝난 뒤에만 엽니다

Windows 런처는 로컬 실행과 Defender 검토까지 통과했습니다. 다만 고객에게 배포하려면 파일 출처를 증명하는 디지털 서명, 변하지 않는 공식 다운로드 주소, 실제 다운로드 파일 기준 Windows 보호 절차 검증이 필요합니다. 그래서 지금은 다운로드 버튼 대신 도입 문의와 설치 준비 안내만 제공합니다.

통과

로컬 실행 검토

Windows에서 압축 해제 후 런처 실행을 확인했습니다. 메인 창이 정상 응답했고 검증 후 종료했습니다.

통과

Defender 검토

실시간 보호 상태에서 압축 해제와 실행 중 차단/격리는 관찰되지 않았습니다.

보류

디지털 서명

이 파일이 진짜 아르센에서 만든 것이 맞다는 디지털 도장을 받는 절차가 남아 있습니다. 이 도장이 있어야 Windows가 출처를 더 쉽게 확인합니다.

보류

공식 다운로드 주소

변하지 않는 공식 주소를 정한 뒤, 인터넷에서 받은 파일을 Windows가 안전하게 확인하는 절차를 다시 통과해야 합니다.

고객용 정식 파일은 공식 다운로드 주소와 디지털 서명 검증이 끝난 뒤 안내합니다. 테스트 빌드나 출처가 불분명한 파일은 실행하지 말고, 공식 페이지의 파일 크기와 검증 번호를 함께 확인하세요.

문의와 피드백

문제가 생겼을 때도
어디로 보내야 하는지 보이게

초보자에게 중요한 건 오류 메시지보다 다음 행동입니다. 런처와 웹페이지 모두 피드백 종류, 로그 첨부 동의, 접수 상태를 분리해서 보여주는 방향으로 맞췄습니다.

피드백 접수 흐름

사용자가 “안 된다”고 느끼는 순간에 바로 문의할 수 있어야 합니다. 단, 민감한 로그나 계정 정보가 그대로 저장되지 않도록 동의와 마스킹 단계를 둡니다.

  • 문제 유형 선택: 로그인, 업데이트, 초안 생성, 결제, 기타
  • 사용자 설명 입력: 어떤 버튼을 눌렀고 어떤 문구가 나왔는지
  • 로그 첨부 동의: 선택 사항이며 민감 정보는 마스킹
  • 접수 번호 표시: 운영자가 확인할 수 있는 기준 ID 제공

FAQ

AI가 쓴 글을 제가 수정할 수 있나요?
네, 반드시 수정할 수 있습니다. 생성된 모든 초안은 승인 대기 상태로 전달되며, 발행 전에 자유롭게 편집·수정할 수 있습니다. 승인을 누르지 않으면 외부에 공개되지 않습니다.
검색 상위 노출을 보장해 주나요?
아니요. 아르센 블로그 자동화는 초안 생성 및 콘텐츠 운영 효율화 도구입니다. 검색 노출 순위는 검색 엔진 알고리즘에 따라 결정되며, 특정 순위나 트래픽을 보장하지 않습니다.
생성된 글이 외부로 자동 발행되나요?
기본값은 '발행 대기'입니다. 사용자가 직접 승인하기 전까지 외부 플랫폼(블로그, SNS 등)에 자동으로 게시되지 않습니다. 자동 발행을 원하는 경우 별도 설정이 필요합니다.
런처를 꼭 설치해야 하나요?
웹 대시보드만으로도 기본 기능을 이용할 수 있습니다. 다만 Windows 런처를 설치하면 공지 수신, 업데이트 알림, 원클릭 실행 등 편의 기능이 추가됩니다. 선택 사항입니다.
Windows 보안 경고가 뜨면 어떻게 하나요?
정식 디지털 서명 전 테스트 빌드나 인터넷에서 내려받은 파일은 Windows가 처음 보는 파일이라고 보호 메시지를 띄울 수 있습니다. 현재는 고객용 정식 다운로드를 열기 전 단계이며, 공식 다운로드 주소와 검증 번호를 준비한 뒤 다시 확인해 안내할 예정입니다. 출처가 불분명한 파일은 실행하지 마세요.
페이지에 보이는 런처 화면이 실제 프로그램 화면인가요?
아니요. 현재는 홈페이지에서 제품 흐름을 설명하기 위한 예시 화면입니다. 실제 Windows 런처 UI는 아직 수정 중이며, 화면이 확정되면 이 영역을 실제 화면 기준으로 교체합니다.
내 블로그 데이터가 외부에 공유되나요?
초안 생성 과정에서 입력한 주제와 내용은 AI 처리에만 사용됩니다. 제3자에게 판매하거나 광고 목적으로 사용하지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.
플랜을 중간에 업그레이드할 수 있나요?
언제든 플랜을 변경할 수 있습니다. 업그레이드 시 당월 남은 기간 기준으로 차액이 정산됩니다. 다운그레이드는 다음 결제 주기부터 적용됩니다.
macOS나 Linux도 지원하나요?
현재 런처 앱은 Windows 전용입니다. 웹 대시보드는 모든 플랫폼 브라우저에서 사용 가능합니다. macOS 런처는 로드맵에 있으며, 출시 시 공지를 통해 안내드립니다.
